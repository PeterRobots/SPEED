Abstract

Diffusion models have recently achieved strong results in Video Frame Interpolation (VFI), but existing latent diffusion approaches still lose fine-grained details during VAE encoding/decoding and suffer from expensive multi-step sampling. SPEED addresses both limitations with a one-step pixel diffusion framework: it performs interpolation directly in RGB pixel space and generates the intermediate frame with a single forward pass.

SPEED combines a progressive multi-stage Transformer, Noise-Update-Only Attention, and Drift-aware Timestep Sampling. The model first captures global motion with large patches, then refines structural alignment, and finally synthesizes high-frequency textures with fine-grained patches. This design preserves sharp details while improving inference speed and memory efficiency.

Highlights

Pixel-Space Diffusion

Performs VFI directly in RGB pixel space, avoiding the VAE-induced detail loss of latent diffusion baselines.

One-Step Inference

Bypasses iterative denoising and predicts the intermediate frame from Gaussian noise in a single model forward pass.

Efficient Global Attention

NUO Attention updates only noisy target tokens while preserving clean condition-frame semantics and reducing attention cost.

Pipeline

SPEED uses endpoint frames as conditions and predicts the intermediate RGB frame with a progressive pixel-space Transformer. Patch sizes decrease from 64 to 32 and then 16, following a macroscopic-to-microscopic generation process.

Performance

SPEED establishes a new state of the art on DAVIS, SNU-FILM, and XTest4K while reducing the runtime and memory cost of diffusion-based VFI. On SNU-FILM Extreme, SPEED improves LPIPS by 8.8% over EDEN. On XTest4K, it achieves 0.1070 LPIPS and 0.1484 FloLPIPS while maintaining low memory usage for 4K interpolation.

Code Release

The repository provides scripts for model training, evaluation, and inference. Since SPEED is trained for one-step generation, image-pair inference and video interpolation through inference.py require only one forward pass for each intermediate frame. Video interpolation can run in parallel mode for higher throughput or sequential mode for lower memory usage. 

python inference.py \
  --config configs/eval_config.yaml \
  --pretrained_path checkpoints/speed.pt \
  --frame0 examples/frame_0.png \
  --frame1 examples/frame_1.png \
  --output interpolation_outputs/interpolated.png \
  --precision bf16
